# Customer Onboarding Runbook

1. Agreement signed, including data processing terms and hosting location.
2. Create a new site for the customer; install erpnext, hrms, nortix.
3. Load fixtures (roles, workspaces, default settings).
4. Apply the customer brand (ADR-0006): brand name, logos, favicon, login page, email footer, letter heads per Company; check the phone app name and icon.
5. Create Companies, Branches, Departments, Designations, Holiday Lists.
6. Review every settings DocType with the customer's HR and Finance; record changes.
7. Import masters with the migration tools; reconcile.
8. Create users with roles and User Permissions; enable 2FA for privileged roles.
9. Configure backups, monitoring and email.
10. Train users; run a parallel period; sign-off.
