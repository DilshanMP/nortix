# Glossary

| Term | Meaning |
| --- | --- |
| Nortix | The product name used in code, Git and documentation |
| Customer brand | The name and logo a customer's staff see on their site (e.g. Akvora One) |
| Site | One Frappe installation with its own database; one per customer organisation |
| Company | A legal entity inside a site, with its own books |
| Branch | A location of a company (head office, service centre, warehouse) |
| Workspace | A department's menu, shortcuts and reports in the web app |
| DocType | A record type in Frappe; defines table, form, list, API and permissions |
| Submittable document | A DocType that becomes read-only after submit; corrected by cancel and amend |
| 1-year mark | Confirmation date: join date plus 12 months |
| Leave period | The calendar year used for leave entitlement |
| Quarter amount | First-year annual leave set by the quarter of the 1-year mark (14, 10, 7, 4) |
| Settings DocType | A single record holding customer-configurable rules |
| Localisation | Country-specific rules such as EPF, ETF and APIT |
| PWA | Installable web app used on phones (Frappe HR at `/hrms`) |
| ADR | Architecture Decision Record |
| RPO / RTO | Maximum acceptable data loss / time to recover |
