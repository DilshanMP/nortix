# Definition of Done

A requirement is done when:
- [ ] Its status was Confirmed before build
- [ ] Every acceptance criterion has a passing test, recorded in traceability.csv
- [ ] Wrong-role and other-company tests pass
- [ ] CI green: lint, secrets, SAST, tests
- [ ] Security review done; findings fixed or accepted with a reason
- [ ] Docs updated: data dictionary, user notes, changelog
- [ ] Reviewed and merged through a pull request
- [ ] Verified on staging by the business owner
