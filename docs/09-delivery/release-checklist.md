# Release Checklist

- [ ] All included requirements meet the Definition of Done
- [ ] CI passed on the release tag
- [ ] Patches reviewed and tested on a staging copy of production
- [ ] Security readiness checklist complete (Master Plan, Security and operations)
- [ ] Backup taken and a restore tested within the last month
- [ ] Monitoring and alerts working
- [ ] Branding checked on a second test site with a different brand (ADR-0006)
- [ ] Rollback steps written and tested on staging
- [ ] Business owner sign-off recorded
- [ ] Release notes and CHANGELOG ready
