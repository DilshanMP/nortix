# Roadmap

| Phase | Content | Gate |
| --- | --- | --- |
| 1. Discovery | D2–D8 decided; Q1–Q8 answered; leave Sheet cleaned; LV register confirmed | Owner approves requirements and decisions |
| 2. Architecture and proof of concept | Test site with 6 companies and workspaces; annual rule and one device sync proven | Proof of concept works on synthetic data |
| 3. UX prototype | Leave screens, HR workspace, phone app configured; users try them | Users accept the screens |
| 4. Foundation | Repo, CI, staging, backups, 2FA, roles, audit, Cloudflare | CI passes; restore drill meets RTO |
| 5. Incremental delivery | R1 leave → R2 attendance and payroll → R3 admin and IT → R4 finance office | Each release reconciled and signed off |
| 6. Migration and verification | Clean imports, parallel runs, load and security tests, UAT | Figures match; security checklist complete |
| 7. Controlled launch | Pilot one company, then all; monitoring and support | ERP requirements analysis decides the ERP-stage platform |
| ERP stage | Phases 1–7 again for purchasing, stock, warehouse, sales, accounts, audit | Per area |

Dates are added after Phase 1.
