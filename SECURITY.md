# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to the product owner. Do not open a public issue. Include the affected version, steps to reproduce and impact.

Target response: acknowledgement within 2 working days; assessment within 7 days; fix or mitigation according to severity.

## Supported versions

Only the latest release on the `main` branch receives security fixes.

## Scope rules

- Test only environments you own or have written permission to test.
- Never run destructive scans against production.
- Personal data found during testing is reported, not copied or shared.

See `docs/05-security/` for the security architecture, threat models and incident response.
