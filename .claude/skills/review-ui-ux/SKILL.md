# UI and UX review

Check against docs/ux/ux-guidelines.md:
1. Does each role see only what it needs?
2. Can the main journey be done in the fewest steps, on phone where staff use it?
3. Are validation messages specific and actionable?
4. Labels, keyboard use, focus and contrast (WCAG 2.2 AA target)?
5. Is every hidden button or field also protected on the server?

Output: issues by severity with suggested fixes.
